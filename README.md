# Synthetic Population Pipeline — Patras

Filters, spatially places, and validates a synthetic population (`households.json`)
onto OSM building footprints in Patras, Greece.

---

## Repository layout

```

filter_patras.py            ← Pipeline step 2: extract Patras from full Achaia output
reweight_s3.py              ← S3 sensitivity: reweight household templates
stability_run.py            ← 10-run stability check

    main_ipf_pipeline.py    ← entry point; seed controlled by PIPELINE_SEED env var (default 42)

  util.py                   ← load_districts(), CRS helpers
  schools.py                ← school shapefile preprocessing
  assignment.py             ← household→building spatial assignment (standalone)

  verify_population.py      ← structural validation (pass path as argument)

  compute_jsd.py            ← JSD vs. WG reference distribution

  age_structure.py          ← synthetic vs. ELSTAT age pyramid

  abm_conditional_stats.py  ← conditional ABM stats (excludes stochastic extinction)

figures/                    ← figure generation scripts
  generate_abm_figures.py   ← epidemic curves + peak comparison
  generate_coresidence_figure.py ← singleton rate by age band
  visualize_gis.py          ← 5 GIS assignment figures
```

## Prerequisites

### 1. Python environment

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m ensurepip --upgrade
pip install geopandas shapely folium pandas numpy scipy matplotlib jupyter ipfn
```

### 2. Geofabrik OSM extract (required for Stages 4–8)

Download the Greece shapefile extract from Geofabrik (date code `260611`, released 2026-06-11)
and place the unpacked folder at:

```
data/greece-260611-free.shp/
```

The pipeline uses two files from inside that folder:
- `gis_osm_landuse_a_free_1.shp`
- `gis_osm_buildings_a_free_1.shp`

Stages 1–3 and the validation cells (Stage 9) run without this file.

### 3. Input data

**Not yet present in this folder.** See [DATA_SETUP.md](DATA_SETUP.md) for exactly what to copy
in and from where. Once set up, the layout is:

```
data/synthpop/households.json               # full Achaia synthesis output (119,070 HH)
data/synthpop/patras_households.json        # Patras-only filter (82,507 HH, 215,927 people)
data/SCHOOLS/sxoleia.csv                    # national Greek schools CSV
data/PATRAS_GIS_DATA/GEITONIES_PATRAS/      # 55 Patras district shapefiles
```

## Running the GIS pipeline

Launch Jupyter from the project root:

```bash
jupyter notebook
```

Open `pipeline.ipynb` and run top-to-bottom. All stages are in one file.

The band-14 gate (Stage 2) asserts that the age 70–74 cohort solo rate is below 99%.
The current `households.json` passes this gate (band-14 solo rate: 13.5%).

---

## Running the synthesis

```bash
cd Thesis_Synthpop-main/python_ipf
python main_ipf_pipeline.py
```

Output: `ipf_results/households.json` (full Achaia, ~306K individuals).
Copy to `../../data/synthpop/households.json` before running `pipeline.ipynb`.
Set `PIPELINE_SEED` environment variable to override the default seed of 42.

## Known limitations

- **Urban-core scope:** the district shapefile covers 187,554 people (urban core, 55 districts).
  The full Patras municipality file contains 215,927 people. The ~28,373 gap (~13%) are people
  in peripheral areas with no eligible OSM residential footprint; they are not placed by this
  pipeline. See [population_canonical.md](population_canonical.md).
- **Orphan buildings:** 2,651 of 35,256 eligible buildings (7.5%) lie outside all district
  polygons (boundary-edge leakage, concentrated 27.5% in the peripheral district ΕΓΛΥΚΑΔΑ).
  These buildings are excluded from household assignment.
- **Sparse OSM type coverage:** only 2.0% of buildings have a meaningful OSM `type` tag.
  The remaining 98% receive a uniform default capacity of 3 households. The type-aware capacity
  model is formally correct but barely active; the manuscript should describe this honestly.
- **No centroid fallback:** households are placed only in real building footprints. Manuscript
  Section 7.3 previously described a centroid-fallback category — that category does not exist
  and the description must be removed. Stage 9d asserts `fallback == 0`.
- **Distance in degrees:** nearest-school assignment uses EPSG:4326. School ranking is correct;
  reported distances would be in degrees. Reproject to EPSG:2100 (Greek Grid) for distance
  metrics.
- **`gis/assignment.py` is now seeded** (`PIPELINE_SEED`, default 42) for reproducible
  household-to-building placement, fixing an earlier non-determinism bug (`np.random.shuffle`
  with nothing seeding it beforehand) that caused aggregate/district totals to vary by up to ~2%
  between runs (district rank order was stable). The canonical `data/gis_district_statistics.csv`
  and manuscript numbers come from one specific historical run predating the fix, so a fresh
  seeded run will not reproduce it bit-for-bit. A second, related bug: 4 districts previously
  shared one internal `GEIT_ID`, now worked around in `figures/visualize_gis.py` by keying on
  `DISTRICT_ID` instead.
